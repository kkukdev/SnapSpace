# 📄 스마트폰 및 AI 기반 제조 현장 3D 스캔 솔루션 개발

# 1. App

## **✔ 환경 요구사항**

- Android 7.0 이상(API : 24 이상)
- 테스트 환경 : Android 13(API 33) ??(병국이 환경이랑 확인필요)
- Google Play(Play 스토어)에서 “**Google Play AR 서비스”**설치 필요

# 2. Retouch

## **✔ 환경 요구사항**

- OS: **Windows 11 + WSL**, 또는 Linux
- Python **3.10+**, Blender **4.5 LTS+**
- NVIDIA GPU + CUDA 빌드 PyTorch 환경 필요
- Blender 절대경로 필요 (`blender.exe`)
- AI 인페인트는 CUDA 기반 torch 필수

## **✔ 사용 패키지**

- **Mesh/Geometry**: open3d, numpy, pymeshlab, trimesh
- **Texture/AI**: opencv-python, Pillow, scikit-image, torch, diffusers, transformers, accelerate
- **Blender**: bpy(Blender 내부 제공)

## **✔ 외부 도구·데이터**

- HI/LO 샘플 OBJ: `Texture/datasets/obj/`
- Blender 스크립트는 **headless 모드**에서 `python`으로 실행
- 출력 구조: `outputs/hybrid/pipeline`

## **✔ 경로 처리**

- Windows/WSL 혼합 지원
- `/mnt/c/...` → Windows 경로로 변환하는 기능 있음
    - `to_windows_path`: texture_pipeline.py (61–95 line)

# 3. Backend

## **✔ 환경 요구사항**

- **Docker** 설치 필요
- **.env 파일** 필수 (데이터베이스 설정)

### 1. 환경 변수 설정

`# .env 파일 생성(예시) (BackEnd/app/.env)POSTGRES_DB=fastapi_db
POSTGRES_USER=postgres
POSTGRES_PASSWORD=password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
TIMEZONE_OFFSET=9`

### 2. 전체 스택 실행

`# PostgreSQL + FastAPI 함께 실행docker-compose up --build -d# 로그 확인docker-compose logs -f# 중지docker-compose down

# 중지 및 container에 저장되어 있는 volume(DB)까지 삭제docker-compose down -v`

### 3. 개발 모드 (로컬에서 FastAPI만 실행)

`# 가상환경 활성화venv\Scripts\activate     # Windows# 또는source venv/bin/activate  # Linux/Mac# 의존성 설치pip install -r requirements.txt

# PostgreSQL만 Docker로 실행docker-compose up postgres -d# FastAPI 서버 실행python -m app.main`

## 기본 엔드포인트
